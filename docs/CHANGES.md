## Data files (fixed)
* `variables.json` was invalid JSON (trailing comma) and used look-alike Unicode letters; now valid, 55 variables
  covering **all** identifiers used by the 42 formulas.
* `constant.json`: key had trailing spaces, `μ₀` was `4π*10-7`, `h` appeared twice, a comma sat inside a number,
  units were lowercase (`f/m`, `t.m/a`, `j.s`), numbers were strings. Now numeric, correct units.
* `keyboard.json`: an object loses key order in Qt, so it is now an ordered array of groups; keys that
  cannot be used in a number field were removed.
* `formulas.json`: all 42 formulas kept. Added `"units"` overrides (phi in Malus' law is degrees,
  f in mirror/lens formulas is metres).

ExpressionEvaluator, EquationSolver (numeric), SolverEngine, unit tests (core + real-data round trip of every

# Version 2.2 (patch on 2.1 - changed files only)

* Window opens maximised, F11 toggles full screen. DSEG Casio-style segment fonts on the Calculator page only.
* Nine new Figma frames: six experiments (Newton's rings, Michelson, thin film, diffraction grating, single slit, Malus/Brewster)
  with Save/Export header and Send to Notes; Equation Lab; "Scientific input" keyboard (Greek / Math operators / Functions / Variables).
* keyboard.json: Figma layout + all 55 variables of variables.json. LaTeX-rendered formulas (notes preview, formula reference).
* **Export (Excel/CSV)** is its own screen: every data series with its description and columns, the **full** table (the Notes
  page shows a 7-row sample), the workbook/CSV settings on the right, and a **recent export** card that remembers the last
  file in the `.phy` session (session format version 4; version 3 files still load). The Notes page keeps its quick export
  and both write the same record. Dashboard "Export data" and the Export header of the six new screens open it.
* **Second tabs do something**: the Fringes tab of Michelson, the Transmission tab of Thin-Film and the Viewing-mode
  dropdown of Newton's rings now reach the engine instead of only resetting. Thin film shows `I_t/I_t,max = cos²(2πnt/λ)`
  (the exact complement of the reflection tab, no net phase reversal, first dark at λ/(4n)) with the transmitted beam drawn
  instead of R1/R2; Michelson keeps the mirror fixed and reports the spacing λ/(2n) and the fringe count over a ±2 µm sweep
  on a 601-point chart; the beam-balance dropdown now really sets the fringe contrast V, the reference-arm dropdown puts
  M1 on a piezo stack, and Newton's transmitted dark rings sit at half orders `(m + ½)λR/n`. Diagram and chart panels are
  re-captioned per mode. Rewired: engine inputs grew a mode flag (`fringes`/`piezo`, `transmission`, `transmitted`).
* **The other three second tabs are real too**: Grating *Orders* lists every propagating order with its angle
  (θ₂ − θ₁ = 19.41° against θ₁ = 17.46°, `d/λ = 3.3333`) and marks all 7 peaks on the intensity chart; Single slit *Geometry*
  puts the minima on the screen (`y₁ = ±5.0001 mm`, `y₂ = ±10.0005 mm`, side maximum at 1.43 θ₁) with a `yₘ`-vs-order chart
  and dashed rays in the drawing; Malus/Brewster switches to the interface at θB, `R_p = 0`, `R_s = 0.1479` (14.8 % reflected
  at θB, 4 % at normal incidence) and plots `R_p(θ)` from 0.04 down to 0 at 56.31° and up to 1 — all six model screens now
  react to their tabs (`orderList`, `geometry`, `brewster`).
* **PDF Report** page (print): one document with the header, every experiment's headline, diagram and chart
  (captured live from the screens at 2x), the parameters, the LCD registers, the session notes (Markdown rendered)
  and the table of saved calculations. Ticks choose what goes in, A4 portrait or landscape, a live preview on the
  right, **Save PDF** into the chosen folder and **Print…** through the system dialog. The HTML is built by the
  tested core module `ReportDocument` (escaping, options, `img://` keys); the Qt layer only attaches the pixmaps.
  The written file lands in the same "recent export" card and `.phy` session as the Excel/CSV exports.
* **Draw Space** page: whiteboard for optics sketches (pen, line, ray, rectangle/ellipse, lens, mirror, prism, interface,
  axis, normal, text and LaTeX labels), select/move, Delete, undo/redo, 8 px grid snap, six colours, three widths, PNG (2x)
  and SVG export. The sketch autosaves into the `.phy` session and is restored on start (`Drawing` engine unchanged).
* Fixed: formulas typed half-way (e.g. \frac{1}) crashed the LaTeX renderer.
* Fixed: the notes preview showed no formulas. Qt's Markdown importer silently drops an image with an empty alt text
  (`![](…)`), so every generated formula image is now `![formula](latex://N)`; an image the student writes without alt
  text is rescued to `![image](…)` before import (fenced code is left alone). The interaction test asserts both.
* **Compare saved runs** on the dashboard: the "Recent calculations" panel gained a **Recent / Compare** switch. Compare
  shows two run pickers (Run A / Run B) and overlays both sweeps on one amber/blue chart with a legend and a summary
  (`RUN 001 (exp) · N points vs RUN 002 (exp) · M points`). Runs are only offered when they carry a sweep, the previous
  choice is kept across refreshes, and the newest pair is picked by default. The rows of the Recent table are now
  selectable and **Delete selected run** removes the run (and its sweep) from the session, autosaves the `.phy` file and
  reports it in the status bar. For that, a run now keeps the sweep it was calculated with: `RunRecord::series`,
  remembered by `AppContext` from the last `publish()` of each experiment, written as `"series"` per run in the session
  file (**format version 5**, version 4 and older files still load) and `SessionLog::removeRun(id)`.
* **Continuous integration**: `.github/workflows/build.yml` builds on every push to `new-v2.1`/`main` and on every pull
  request - Linux (Qt 6 + Ninja + ctest), Windows (MSVC, Qt 6.7.2 through `install-qt-action`) and a Qt-free job that
  compiles the core with plain `g++` and runs `tests/test_core.cpp`. UI tests run with `QT_QPA_PLATFORM=offscreen`.

# Version 2.3 - full-width pages, one export icon, leaner screens

* **Every page fills the window.** `BasePage` no longer caps the content at 1500 px and centres it, so the whole
  window is used end to end (the empty strips left and right of a maximised window are gone). Fixed side columns of
  the experiment screens keep their width; only the middle column grows.
* **One export icon in every header** (new `download` Lucide icon, amber, with a menu and its own dark/light styling):
  **PDF report…**, **Excel (.xlsx)…**, **CSV (.csv)…**. PDF opens the report screen; Excel/CSV open the
  Export screen with that format already selected (`ExportPage::setFormat`). The old per-page "Export" text button and
  the `exportRequested()` signal are gone; the Equation Lab keeps its own **Export PNG** button for the rendered equation.
* **Notes page is only the Markdown workspace** (as in the Figma screen): the "Formula reference" panel, the
  "Export preview" table and the "Export (Excel/CSV)" settings panel were removed. The reference lives on the
  Formula Solver page, the settings on the Export page; the session notes, snippet toolbar, live LaTeX preview and
  autosave are unchanged.
* **Draw Space removed** at the author's request: the page, its sidebar entry, its sources and its click-through tests
  are gone. The `Drawing` core model stays (the `.phy` file keeps its `drawing` key, older sessions still load).
* Tests updated: the header test checks the three menu entries, a new test drives them (Excel, CSV, PDF) and checks the
  Notes page carries no export UI, and the icon list of `test_ui` follows `download`/`pen-tool`.
