## Data files (fixed)
* `variables.json` was invalid JSON (trailing comma) and used look-alike Unicode letters; now valid, 55 variables
  covering **all** identifiers used by the 42 formulas.
* `constant.json`: key had trailing spaces, `μ₀` was `4π*10-7`, `h` appeared twice, a comma sat inside a number,
  units were lowercase (`f/m`, `t.m/a`, `j.s`), numbers were strings. Now numeric, correct units.
* `keyboard.json`: an object loses key order in Qt, so it is now an ordered array of groups; keys that
  cannot be used in a number field were removed.
* `formulas.json`: all 42 formulas kept. Added `"units"` overrides (phi in Malus' law is degrees,
  f in mirror/lens formulas is metres).

ExpressionEvaluator, EquationSolver (numeric), SolverEngine, unit tests (core + real-data round trip of every
formula/variable, 25 random data sets), Qt UI, five experiments, notes, theme.

# Version 1.2 - UI, search and calculator update

* **Gruvbox theme** (dark + light) with the requested colours; **Casio LCD** styling for formulas, inputs, answers
  and the calculator; orange/red/green status lines for warnings, errors and successful checks.
* **Screen limit + pagination** for the formula list (3/5/10/20 per page) and a history limit in the calculator.
* **FormulaManager**: case-insensitive search by name/ID, chapter filter, 7 PHY104 chapters in course order.
  Formulas now refer to a chapter *id*; titles and order live in `data/chapters.json`.
* **Calculator page** (`MathCalculator` + `MathSolverPage`): free expressions, functions, `pi`, `e`, `Ans`, DEG/RAD.
  `ExpressionEvaluator` gained an `AngleUnit` option (exact `sin(180) = 0` in degree mode).
* **LaTeX**: `LatexRenderer` (QPainter layout engine), `LatexFormatter`, LaTeX for all 55 variables.
* **SVG diagrams**: six diagrams generated by `tools/make_diagrams.py`, theme-aware, smooth scaling, PNG export.
* New tests: FormulaManager, MathCalculator, LaTeX formatter, degree mode, chapters on the real data,
  LaTeX validity of every JSON string, SVG token/render checks in both themes, exact theme colours.

* Window opens maximised, F11 toggles full screen. DSEG Casio-style segment fonts on the Calculator page only.
* Nine new Figma frames: six experiments (Newton's rings, Michelson, thin film, diffraction grating, single slit, Malus/Brewster)
